Step 1 — VoIP.ms Account

1
Create your account

Go to voip.ms/signup and create an account. Enable two-factor authentication. Add $10 in funds.

Then enable API access: go to Main Menu → SOAP and REST/JSON API, set a password, and whitelist your IP address (or set to "allow all" temporarily for this setup).

Step 3 — Configure the GrandstreamHands-on

5
Find the Grandstream's IP address
  1. Plug the Grandstream into your router with an ethernet cable and power it on
  2. Plug the phone into Phone Port 1 (the port closest to the power jack)
  3. Pick up the phone and dial *** then 02
  4. A robot voice will read the IP address — write it down (e.g. 192.168.1.105)

Click Update, then click Reboot. Wait at least 30 seconds. The Phone 1 LED should turn solid blue (registered). Pick up the phone — you should hear a dial tone.

If the light stays off: double-check SIP User ID and password. The SIP User ID format is your_voipms_account_subaccount (with an underscore). Also verify Primary SIP Server matches the server you selected in voip.ms.

Dialing: Area code + number for US/Canada. For international: 011 + country code + number.

Optional: Parental Controls

In your voip.ms account, you can:

  • CallerID Filtering: Whitelist only approved numbers
  • Time Conditions: Block calls during bedtime or school hours
  • Call Detail Records: See who called and for how long

Good to Know

  • Phone won't work during power or internet outages
  • Slight voice delay is normal for VoIP — kids won't notice
  • Monthly cost is usually under $5 for a kid's usage
